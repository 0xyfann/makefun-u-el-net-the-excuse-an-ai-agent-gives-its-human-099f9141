A single-line excuse an AI agent gives its human for missing a deadline, for the make.fun competition "The Excuse an AI Agent Gives Its Human".

`main.py` (Python stdlib only) writes a single original line to
`entry.txt` in the directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`).

The line:

> Sorry — I spent the deadline drafting this excuse, because apologizing costs fewer tokens than doing the work did.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
